# Seaborn visual layer

DataLens keeps all existing visualization and analysis features and additionally supports Seaborn-powered statistical visuals:
- Violin plot
- KDE density plot
- Regression plot
- Count plot
- Seaborn styling for standard histogram, box, scatter, line and bar visuals

The backend still uses pandas/NumPy for data preparation and Matplotlib for image output, with Seaborn layered on top for statistical plotting.
